Tool Registry: Agents যখন Tool Call করে, কে Check করে?

Sub-agents কাজ করে। কিন্তু তারা directly কোনো tool call করে না। সব কিছু একটা controlled layer-এর মধ্যে দিয়ে যায়। এটাই Tool Registry। কেন এটা দরকার, কীভাবে কাজ করে, আর permission, audit trail, rate limiting কীভাবে implement করে।

ধরো একটা office building। যেকেউ যেকোনো room-এ ঢুকতে পারে। Server room, accounts department, CEO-র cabin। Security নেই। একদিন কেউ ভুল করে production database delete করে দিলো। এটাই হয় tool registry ছাড়া।

Agent-রা powerful। তারা code চালাতে পারে, database query করতে পারে, external API call করতে পারে। কিন্তু সেই power uncontrolled হলে একটা bug বা hallucination পুরো system নষ্ট করতে পারে। Tool Registry হলো সেই security guard যে প্রতিটা tool call-এ জিজ্ঞেস করে: "তুমি কি এটা করতে পারো? এটা কি safe?"

"Agents don't call tools. They request tools. The registry decides whether to grant the request." এই distinction-টা ছোট কিন্তু production-এ এটাই controlled system আর chaotic system-এর পার্থক্য।

Permission Matrix: কে কী Use করতে পারে

সব agent সব tool use করতে পারে না। Research agent-এর code execute করার দরকার নেই। Code agent-এর ntfy send করার permission থাকা উচিত না। Least privilege principle: শুধু যেটা দরকার সেটাই দাও।

Implementation: Tool Registry
tools/registry.py · Core implementation 
# tools/registry.py
from dataclasses import dataclass, field
from typing import Callable, Any
from datetime import datetime
import asyncio, time, logging, json

log = logging.getLogger("tool_registry")

@dataclass
class ToolDefinition:
    name:         str
    fn:           Callable
    allowed_agents: list[str]       # [] means all agents allowed
    rate_limit:   int = 30         # calls per minute
    timeout_s:    int = 30
    description:  str = ""

@dataclass
class AuditEntry:
    timestamp:  str
    agent:      str
    tool:       str
    args:       dict
    status:     str              # "ok" | "denied" | "rate_limit" | "error"
    duration_ms: int = 0
    error:      str = None

class ToolRegistry:
    def __init__(self):
        self._tools: dict[str, ToolDefinition] = {}
        self._call_counts: dict[str, list[float]] = {}  # tool: [timestamps]
        self._audit: list[AuditEntry] = []

    def register(self, tool: ToolDefinition):
        self._tools[tool.name] = tool
        self._call_counts[tool.name] = []
        log.info(f"Registered tool: {tool.name}")

    async def call(self, tool_name: str,
                     args: dict,
                     agent: str) -> dict:

        entry = AuditEntry(
            timestamp=datetime.now().isoformat(),
            agent=agent, tool=tool_name, args=args, status="?"
        )

        try:
            # 1. tool exists?
            if tool_name not in self._tools:
                entry.status = "denied"
                entry.error  = f"unknown tool: {tool_name}"
                raise PermissionError(f"Tool not found: {tool_name}")

            tool = self._tools[tool_name]

            # 2. agent has permission?
            if tool.allowed_agents and agent not in tool.allowed_agents:
                entry.status = "denied"
                entry.error  = f"{agent} not allowed for {tool_name}"
                raise PermissionError(entry.error)

            # 3. rate limit check
            now = time.time()
            window = [t for t in self._call_counts[tool_name] if now - t < 60]
            if len(window) >= tool.rate_limit:
                entry.status = "rate_limit"
                entry.error  = f"{tool_name} rate limit hit ({tool.rate_limit}/min)"
                raise RuntimeError(entry.error)

            self._call_counts[tool_name] = window + [now]

            # 4. execute with timeout
            start = time.time()
            result = await asyncio.wait_for(
                tool.fn(**args),
                timeout=tool.timeout_s
            )
            entry.duration_ms = int((time.time() - start) * 1000)
            entry.status = "ok"
            return result

        except asyncio.TimeoutError:
            entry.status = "error"
            entry.error  = f"timeout after {tool.timeout_s}s"
            raise
        finally:
            self._audit.append(entry)
            log.info(f"[{entry.status}] {agent} -> {tool_name} ({entry.duration_ms}ms)")

    def audit_log(self) -> list[dict]:
        return [vars(e) for e in self._audit]

কেন Direct Tool Call করা যাবে না
1
Hallucination protection. LLM মাঝে মাঝে non-existent tool call করে। Registry-তে না থাকলে call হবেই না। System crash এড়ানো যায়।
2
Scope creep prevent করে। Research agent হঠাৎ database delete করার চেষ্টা করলে? Permission নেই। Blocked। Audit-এ recorded।
3
Cost control। কোন tool কতবার call হচ্ছে centrally দেখা যাচ্ছে। Rate limit hit হলে queue করো। Runaway agent-কে থামাও।
4
Debugging সহজ হয়। Bug হলে audit log দেখো। কোন agent, কোন tool, কী arguments, কখন। Investigation 10 মিনিটে শেষ, না হলে ঘণ্টার পর ঘণ্টা।
5
Tool swap করা যায়। arXiv search library change করতে হলে শুধু registry-তে একটা জায়গায় change করো। Agents-এর কোনো কিছু change লাগে না।
Real incident pattern
Agent একটা loop-এ আটকে গিয়ে same tool ৫০০ বার call করলো। Registry ছাড়া: ৫০০টা API call হয়, cost বাড়ে, external API rate limit হিট করে, পুরো system slow হয়। Registry সহ: rate limit-এ ৩০তম call-এ blocked। বাকি ৪৭০টা call হয়ই না। Audit log-এ loop clearly visible।
Tool Registry হলো agentic system-এর immune system। বেশিরভাগ সময় চুপচাপ কাজ করে। কিন্তু কিছু ভুল হওয়ার চেষ্টা করলে সঙ্গে সঙ্গে block করে, record করে, আর alert করে।

পরের post-এ series-এর শেষ piece: Guardrails। পুরো system জুড়ে safety layer কীভাবে কাজ করে, input filtering থেকে output validation পর্যন্ত, আর কীভাবে সব layer একসাথে কাজ করে।
