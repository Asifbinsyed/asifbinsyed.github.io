Skill File-এর Structure

প্রতিটা skill একটা markdown file। চারটা section। Orchestrator এটা পড়ে, relevant section extract করে, agent-এর prompt-এ inject করে।

When to use this skill
Use when agent is asked to replicate an ML paper from scratch. Triggers: "help me replicate", "implement this paper", "reproduce results". Also use when building any training loop, dataset loader, or evaluation script from a research paper description.
How to behave
Always start with ARCHITECTURE.md: write the full plan before any code. Follow the 5-line incremental rule: never write more than 5 lines without running a smoke test. M1 Pro (MPS) first, cloud (CUDA) later. Every function needs a docstring. Every module needs a test.
Hard rules
Never skip the smoke test step. Never. If the paper has ambiguous details, ask before guessing. Log every experiment to W&B from the first run. Use --break-system-packages for pip on this machine. Check MPS availability: torch.backends.mps.is_available()
Output format
After each coding session, update ARCHITECTURE.md with what changed. Commit message format: "[replicate-ml] step N: what was done". End every session with: files created, tests passing, next step.

Implementation: Skill Loader
skills/loader.py · Skill injection system 
# skills/loader.py
from pathlib import Path
from dataclasses import dataclass
import re

SKILL_DIRS = [
    Path("/mnt/skills/user"),      # your custom skills
    Path("/mnt/skills/public"),     # shared skills
    Path("./skills"),               # project-local skills
]

@dataclass
class Skill:
    name:         str
    when:         str     # when to use
    how:          str     # how to behave
    rules:        str     # hard rules
    output_fmt:   str     # output format
    path:         str

    def to_prompt_section(self) -> str:
        """Format skill for injection into agent system prompt."""
        return f"""
## Active Skill: {self.name}

### How to behave for this task
{self.how}

### Hard rules (never violate)
{self.rules}

### Output format
{self.output_fmt}
"""


def load_skill(name: str) -> Skill:
    """Find and parse a SKILL.md file by name."""
    for skill_dir in SKILL_DIRS:
        skill_path = skill_dir / name / "SKILL.md"
        if skill_path.exists():
            return _parse_skill(skill_path)

    raise FileNotFoundError(f"Skill not found: {name}")


def _parse_skill(path: Path) -> Skill:
    content = path.read_text()

    def extract_section(header: str) -> str:
        pattern = rf"#{'{1,3}'}\s*{re.escape(header)}.*?\n(.*?)(?=\n#|\Z)"
        match = re.search(pattern, content, re.DOTALL | re.IGNORECASE)
        return match.group(1).strip() if match else ""

    return Skill(
        name=path.parent.name,
        when=extract_section("when"),
        how=extract_section("how"),
        rules=extract_section("rules"),
        output_fmt=extract_section("output"),
        path=str(path),
    )


def build_agent_prompt(
    identity:     str,
    skill_name:   str,
    memory_ctx:   str,
    task:         str,
) -> str:
    """Assemble complete agent prompt from components."""
    parts = [identity]

    if skill_name:
        try:
            skill = load_skill(skill_name)
            parts.append(skill.to_prompt_section())
        except FileNotFoundError:
            pass  # skill optional, proceed without

    if memory_ctx:
        parts.append(f"## Relevant past context\n{memory_ctx}")

    parts.append(f"## Current task\n{task}")

    return "\n\n".join(parts)
Real Example: Research Agent + Hypothesis Skill
example usage · skill injected into research agent 
# core/pipeline.py
from skills.loader import build_agent_prompt
from agents.research import ResearchAgent
from memory.vector_store import ResearchMemory

async def run_hypothesis_search(
    hypothesis: str,
    memory:     ResearchMemory,
) -> dict:

    # retrieve relevant past context
    past = memory.retrieve(hypothesis, n=5, threshold=0.75)
    memory_ctx = "\n".join(p["content"] for p in past)

    # build prompt: identity + hypothesis skill + memory + task
    prompt = build_agent_prompt(
        identity="""
You are a research agent specializing in ML paper discovery.
Find papers, extract claims, identify gaps. Stay in scope.
""",
        skill_name="hypothesis",   # loads hypothesis/SKILL.md
        memory_ctx=memory_ctx,
        task=hypothesis,
    )

    # agent uses this assembled prompt
    agent = ResearchAgent()
    result = await agent.run(
        task=hypothesis,
        memory_context=memory_ctx,
        skill="hypothesis",         # agent loads skill internally
    )

    # store results back to memory
    memory.store(MemoryEntry(
        content=f"Hypothesis search: {hypothesis}\nGap: {result.output.get('gap_identified')}",
        source="hypothesis_agent",
        tags=["hypothesis", "gap"],
    ))

    return result.output

# Result includes:
# - papers with CLAIM / METHOD / RELEVANCE
# - gap_identified: what hasn't been tested
# - suggested_next_query: what to search for next
# - refined_hypothesis: your original idea + evidence
Skills vs Memory vs MCP: পার্থক্য কী
1
Skills বলে কীভাবে কাজ করতে হবে। Behavior define করে। "5 lines-এর বেশি লিখবে না।" "Smoke test mandatory।" Static instruction set।
2
Memory বলে আগে কী হয়েছে। Dynamic context। "৩ দিন আগে এই topic-এ search করেছিলে, এই papers পেয়েছিলে।" Session-এর বাইরে persist।
3
MCP বলে কোন tool কীভাবে call করতে হবে। Tool connectivity। "arXiv search করতে এই endpoint-এ এই format-এ request পাঠাও।" Protocol layer।
তোমার research harness-এ সব একসাথে
Hypothesis দিলে:
1. Skill Loader: hypothesis SKILL.md load করে
2. Memory: past searches retrieve করে
3. Prompt Builder: identity + skill + memory + task assemble করে
4. Research Agent: এই prompt দিয়ে কাজ শুরু করে
5. Tool Registry: agent-এর tool request validate করে
6. MCP Client: actual arXiv/S2 call করে
7. Result: memory-তে store, ntfy-তে notify, Obsidian-এ save
Skills, Memory, MCP তিনটা আলাদা layer। কিন্তু একসাথে কাজ করে একটা লক্ষ্যে: agent-কে context-aware, consistent, আর connected করা। এই তিনটার combination-ই একটা generic LLM call-কে intelligent research assistant-এ পরিণত করে।
