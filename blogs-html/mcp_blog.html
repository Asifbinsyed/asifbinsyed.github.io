MCP: Tool Registry-র ভেতরে যে Protocol সব কিছু Connect করে

আগের post-এ Tool Registry দেখলাম। কিন্তু registry actual tools-কে কীভাবে call করে? এখানেই আসে MCP: Model Context Protocol। এটা হলো standardized bridge যেটা LLM-কে যেকোনো external tool-এর সাথে একটা common language-এ কথা বলতে দেয়।

আগে প্রতিটা tool আলাদা করে implement করতে হতো। arXiv-এর জন্য আলাদা function। Obsidian-এর জন্য আলাদা। W&B-এর জন্য আলাদা। প্রতিটার error handling, authentication, retry logic আলাদা। Code হয় duplicated, maintenance nightmare। MCP এই সমস্যা একবারে solve করে।

MCP হলো Anthropic-এর open standard। একটা protocol define করে যেটা মেনে tool server বানালে যেকোনো MCP-compatible client সেটা use করতে পারবে। Tool Registry শুধু MCP protocol বোঝে। বাকি সব implementation detail tool server-এ।

MCP হলো USB-C। একটা standard port। যেকোনো device plug করো, কাজ হবে। আগে প্রতিটা device-এর আলাদা cable লাগতো। MCP আসার আগে প্রতিটা tool-এর আলাদা integration লাগতো।

mcp_server.py · Custom research MCP server 
# mcp_server.py
from mcp.server import Server
from mcp.server.stdio import stdio_server
from mcp.types import Tool, TextContent
import arxiv, httpx, json

app = Server("research-mcp")

@app.list_tools()
async def list_tools() -> list[Tool]:
    return [
        Tool(
            name="search_arxiv",
            description="Search arXiv for ML papers by query",
            inputSchema={
                "type": "object",
                "properties": {
                    "query":       {"type": "string"},
                    "max_results": {"type": "integer", "default": 5},
                },
                "required": ["query"]
            }
        ),
        Tool(
            name="search_semantic_scholar",
            description="Search Semantic Scholar with citation data",
            inputSchema={
                "type": "object",
                "properties": {
                    "query":     {"type": "string"},
                    "year_from": {"type": "integer"},
                },
                "required": ["query"]
            }
        ),
        Tool(
            name="fetch_hf_papers",
            description="Get trending ML papers from HuggingFace Papers",
            inputSchema={
                "type": "object",
                "properties": {
                    "date": {"type": "string", "description": "YYYY-MM-DD"},
                },
            }
        ),
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict):
    if name == "search_arxiv":
        client = arxiv.Client()
        search = arxiv.Search(
            query=arguments["query"],
            max_results=arguments.get("max_results", 5),
            sort_by=arxiv.SortCriterion.Relevance
        )
        papers = []
        for r in client.results(search):
            papers.append({
                "title":     r.title,
                "abstract":  r.summary[:600],
                "authors":   [a.name for a in r.authors[:3]],
                "url":       r.entry_id,
                "published": str(r.published.date()),
            })
        return [TextContent(type="text", text=json.dumps(papers))]

    elif name == "search_semantic_scholar":
        async with httpx.AsyncClient() as client:
            r = await client.get(
                "https://api.semanticscholar.org/graph/v1/paper/search",
                params={"query": arguments["query"], "limit": 5,
                        "fields": "title,abstract,authors,year,citationCount"}
            )
            return [TextContent(type="text", text=r.text)]


async def main():
    async with stdio_server() as (read_stream, write_stream):
        await app.run(read_stream, write_stream, app.create_initialization_options())

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())

tools/mcp_bridge.py · Registry connects to MCP servers 
# tools/mcp_bridge.py
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from tools.registry import registry, ToolDefinition

class MCPBridge:
    """Wraps MCP server tools and registers them in ToolRegistry."""

    def __init__(self, server_script: str, allowed_agents: list[str]):
        self.server_script  = server_script
        self.allowed_agents = allowed_agents
        self._session       = None

    async def connect(self):
        params = StdioServerParameters(
            command="python",
            args=[self.server_script],
        )
        self._read, self._write = await stdio_client(params).__aenter__()
        self._session = await ClientSession(
            self._read, self._write
        ).__aenter__()
        await self._session.initialize()

        # auto-register all tools from MCP server
        tools_response = await self._session.list_tools()
        for tool in tools_response.tools:
            self._register_tool(tool)

    def _register_tool(self, mcp_tool):
        # wrap MCP tool call as async function
        session = self._session
        tool_name = mcp_tool.name

        async def call_fn(**kwargs):
            result = await session.call_tool(tool_name, kwargs)
            return result.content[0].text

        registry.register(ToolDefinition(
            name=tool_name,
            fn=call_fn,
            allowed_agents=self.allowed_agents,
            description=mcp_tool.description,
        ))


# --- Bootstrap: connect all MCP servers ---
async def setup_mcp():
    # custom research server (local)
    research_bridge = MCPBridge(

        allowed_agents=["research_agent"],

MCP-র তিনটা Core Concept
1
Tools: Agent যা call করে। arXiv search, Obsidian write এগুলো সব tool। প্রতিটার input schema defined। Registry এই schema validate করে।
2
Resources: Agent যা read করে। Files, database records, API responses। Tool থেকে আলাদা কারণ এটা read-only। Agent passively consume করে।
3
Prompts: Server-defined prompt templates। Agent system prompt-এ inject হয়। এটাই Skills-এর সাথে connect হয়, পরের post-এ details।
তোমার arXiv digest project-এ
এখন: Python functions directly call করছো।
After MCP: same functions MCP server-এ wrap করো।
Benefit: পরে research harness-এ same server use করবে। Code duplicate হবে না। Tool Registry-তে registration automatic।
MCP মানে "আমি এই tool বানালাম একবার, যেকোনো agent যেকোনো system থেকে use করতে পারবে।" Portability। Standardization। Reusability। Production system-এ এই তিনটা জিনিসই long-term maintainability নিশ্চিত করে।
